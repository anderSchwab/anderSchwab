## 📌 Projetos em Destaque

### 🌐 Ethos Gestão Pública

Website institucional desenvolvido em Next.js com painel administrativo
para gerenciamento de conteúdo.

O projeto permite que o cliente gerencie diferentes áreas do site sem
necessidade de alterar o código-fonte.

**Principais recursos:**

- Painel administrativo
- Gerenciamento de notícias
- Gerenciamento de serviços
- Depoimentos
- Clientes e municípios
- Upload e gerenciamento de imagens
- Conteúdo dinâmico
- Design responsivo
- Integração com WhatsApp

**Tecnologias:**

`Next.js` `React` `Firebase` `Firestore` `Storage` `Tailwind CSS`

🔗 [Acessar projeto](https://ethosgestaopublica.netlify.app/)
